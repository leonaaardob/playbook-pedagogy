# Archive — méthode pédagogique LB Academy (3P)

## Pourquoi cette archive

Tu reçois le livrable d'une analyse pédagogique faite pour **LB Academy**, une plateforme e-learning francophone sur l'ingénierie des agents IA.

Point de départ : **trois documents sources** (Atomic Learning / freeCodeCamp, Curriculum agentique, Beyond Atomic Learning).

Objectif demandé à l'époque : tout lire, analyser, et proposer **une méthode / un playbook final** pour la plateforme.

Cette archive contient **uniquement ce livrable**. Pas les documents sources. Pas le catalogue des cours. Pas la matière technique.

## Ce que la méthode 3P tranche (résumé)

- Arc de module en 8 phases : Accroche → Modèle mental → Primitives → Atelier → Variations → Panne → Défi → Ancrage
- Deux types de leçons : geste (≤ 3 min) et comportement (3–8 min)
- Succès stochastique : 3 lancements, majorité ≥ 2/3, budget affiché et éliminatoire
- Gradation : Défi au module, Mission au barreau (fin de cours)
- Lecture libre, validation exigée (blocage doux)
- 15 règles d'or de rédaction

## Ce qui n'est PAS dans cette archive

- Les 3 PDF/DOCX/MD sources originaux
- Les brainstorms déjà tranchés plus tard (clés API, variantes Python/TypeScript)
