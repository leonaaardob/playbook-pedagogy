# 08 — Modes d’échec

| Symptôme | Réponse |
| --- | --- |
| Preuve absente | revenir au preflight |
| Contrat déterministe échoué | corriger le contenu ou le code, puis relancer le contrôle |
| Résultats variables contradictoires | échantillonner, documenter, escalader à l’humain |
| Variante non équivalente | la retirer ou la traiter comme parcours distinct |
| Projection sans source validée | bloquer la publication |
| Rendu ou test non vérifié | bloquer la publication et reprendre le contrôle |
| Correction non recontrôlée | relancer le dernier contrôle applicable |
