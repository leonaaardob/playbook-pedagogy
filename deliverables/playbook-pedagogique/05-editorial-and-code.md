# 05 — Éditorial et code

## Éditorial

Le contenu est en français et s’adresse à l’apprenant en tutoiement. Les termes métiers anglais sont définis à l’usage. Les objectifs décrivent une action et un résultat observable ; les prérequis précèdent leur usage ; une unité porte une idée principale ; la solution n’est pas révélée avant la tentative.

## Code et parité

Le code est vérifié avant publication. Une variante Python et une variante TypeScript portent le même objectif pédagogique, la même fixture, le même contrat, le même cas limite, les mêmes critères et la même difficulté. Les différences internes peuvent être idiomatiques si la correspondance est explicite.

## Fournisseurs

La doctrine est indépendante des fournisseurs. OpenRouter est optionnel et peut servir de proxy sécurisé ; la clé personnelle passe par le proxy sécurisé. Une variante ne change ni l’objectif, ni l’évaluation, ni les preuves attendues.
