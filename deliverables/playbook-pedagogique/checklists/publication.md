# Checklist — publication

- [ ] contenu validé et version identifiée
- [ ] objectif, prérequis, artefact et critères explicites
- [ ] code vérifié
- [ ] variantes paritaires vérifiées
- [ ] contrôles déterministes réussis
- [ ] évaluations variables documentées
- [ ] revue humaine terminée lorsque le périmètre l’exige, sinon condition documentée
- [ ] tests exécutés
- [ ] rendu contrôlé
- [ ] traçabilité source-projection enregistrée
- [ ] dernier contrôle relancé après correction

**Verdict :** publier / corriger / bloquer
